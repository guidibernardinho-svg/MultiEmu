# MultiEmu 🕹️

MultiEmu is a simple Android frontend for launching your favorite emulators from one place.

## Features
- Clean lightweight design
- One tap emulator launcher
- Auto opens installed emulator apps
- Redirects to Google Play Store if emulator is missing
- Supports multiple classic consoles

## Supported Consoles
- NES (RetroArch / NES.emu)
- SNES (Snes9x)
- PlayStation 1 (DuckStation)
- Nintendo 3DS (Citra)
- Wii / GameCube (Dolphin)
- PlayStation 2 (AetherSX2 / PCSX2 Android)
- Nintendo DS (DraStic)
- Sega Genesis
- Dreamcast (Redream / Flycast)

## Platform
- Android (APK)

## Build
This project uses GitHub Actions for automatic APK building.

## Installation
1. Download APK from Actions artifacts
2. Install on Android device
3. Open MultiEmu
4. Tap your console
5. Launch emulator

## Goal
MultiEmu was made to keep all your emulators in one organized app.
